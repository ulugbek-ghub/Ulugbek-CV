# Ulugbek CV

Personal portfolio and CV built with React + Vite + Tailwind CSS.

## Tech Stack

- **React 19** — UI library
- **Vite 8** — Build tool and dev server
- **Tailwind CSS v4** — Utility-first CSS
- **Framer Motion** — Page transition animations
- **React Router v7** — Client-side routing

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Lint

```bash
npm run lint
```
